## Working extraction snippets

### Browser-console search extractor (run after browser_navigate to the search URL, or via same-origin fetch for batches)
```js
(async () => {
  async function grab(q) {
    const res = await fetch('https://www.amazon.fr/s?k=' + encodeURIComponent(q), {headers: {'Accept-Language':'fr-FR,fr;q=0.9'}});
    const doc = new DOMParser().parseFromString(await res.text(), 'text/html');
    return Array.from(doc.querySelectorAll('div[data-component-type="s-search-result"]')).slice(0,8).map(r => {
      const t = (r.querySelector('.a-color-base.a-text-normal')?.innerText || r.querySelector('h2')?.innerText || '').replace(/\s+/g,' ').trim();
      const l = r.querySelector('a[href*="/dp/"]');
      const p = r.querySelector('.a-price .a-offscreen')?.innerText || '';
      const rt = r.querySelector('.a-icon-alt')?.innerText || '';
      const rv = (r.querySelector('span[aria-label*="évaluations"]')?.getAttribute('aria-label') || r.querySelector('.s-underline-text')?.innerText || '').replace(/\s+/g,' ').substring(0,30);
      const sp = !!r.querySelector('.puis-sponsored-label-text');
      return {t: t.substring(0,105), p, rt, rv, sp, u: (l?.href||'').split('?')[0]};
    }).filter(x => x.t && x.u && !x.sp);
  }
  const out = {}; out['query 1'] = await grab('query 1'); out['query 2'] = await grab('query 2'); out['query 3'] = await grab('query 3'); return out;
})()
```
Keep ≤3 queries per call, no sleeps, slice(0,8).

### jina-reader fallback (browser backend down; also product pages)
```python
import urllib.request, re
def jina(url):
    req = urllib.request.Request('https://r.jina.ai/' + url, headers={'User-Agent':'Mozilla/5.0'})
    return urllib.request.urlopen(req, timeout=45).read().decode('utf-8', errors='replace')
# search page: parse blocks '## [Title](https://.../dp/ASIN)' then scan next ~1200 chars for €price / "N out of 5 stars" / "(N)"
# product page: '^Title: (.+)$' line gives the exact variant title (e.g. "…0-6 Months")
```
Rate-limit: ~5-8 consecutive searches then empty pages — pause or go back to browser; product pages more forgiving.
